# ADR-0020: Policy compiler — deterministic, fail-closed, OSS-only, two-tier budgets
- **Status**: accepted · 2026-08-20 (design 03, critique PASS r2)
- **Context**: agentgateway 2.2 (post-kgateway split); budget/spend limits are Solo Enterprise; same-level policy-overlap semantics not crisply documented (research item R1); gateway runs 1–2 replicas with local counters.
- **Decision**: (1) Compiler is a pure, total library in the operator: every intent field maps or compile-errors; deterministic output incl. name truncate+hash rule; `gatewayReplicas` is a declared input. (2) One concern per policy (field-disjoint, conflict-checked) — avoids same-level ambiguity by construction; R1 reproducing test at implementation. (3) **Fail-closed apply ordering**: Backends → Policies → verify Accepted → Routes last; removal reversed; `PolicyApplyIncomplete` on any gap — no fail-open windows. (4) **Two-tier budgets** (tokens and usd): gateway = conservative local approximation (rate ÷ replicas, max-price across allowed models, unmatched model ⇒ compile error), exact tier = receipt backstop (design 04 aggregate, 00:00 UTC windows) driving `BudgetExhausted` + weight-0. No external rate-limit service, no Redis. (5) KG scope is **gateway-injected (signed header), provider-enforced** across all four fact-bearing kgp tools; gateway never parses MCP bodies. (6) Credential-scrub and card-discovery routes are compiled concerns.
- **Consequences**: Budget semantics are honestly tiered and documented; providers carry scope enforcement (kgp conformance battery); design 01/02 amendments recorded in their §11.
