# ADR-0020: Policy compiler — deterministic, fail-closed, OSS-only, two-tier budgets
- **Status**: accepted · 2026-08-20 (design 03, critique PASS r2)
- **Context**: agentgateway 2.2 (post-kgateway split); budget/spend limits are Solo Enterprise; same-level policy-overlap semantics not crisply documented (research item R1); gateway runs 1–2 replicas with local counters.
- **Decision**: (1) Compiler is a pure, total library in the operator: every intent field maps or compile-errors; deterministic output incl. name truncate+hash rule; `gatewayReplicas` is a declared input. (2) One concern per policy (field-disjoint, conflict-checked) — avoids same-level ambiguity by construction; R1 reproducing test at implementation. (3) **Fail-closed apply ordering**: Backends → Policies → verify Accepted → Routes last; removal reversed; `PolicyApplyIncomplete` on any gap — no fail-open windows. (4) **Two-tier budgets** (tokens and usd): gateway = conservative local approximation (rate ÷ replicas, max-price across allowed models, unmatched model ⇒ compile error), exact tier = receipt backstop (design 04 aggregate, 00:00 UTC windows) driving `BudgetExhausted` + weight-0. No external rate-limit service, no Redis. (5) KG scope is **gateway-injected (signed header — *wrong; see Erratum below*), provider-enforced** across all four fact-bearing kgp tools; gateway never parses MCP bodies. (6) Credential-scrub and card-discovery routes are compiled concerns.
- **Consequences**: Budget semantics are honestly tiered and documented; providers carry scope enforcement (kgp conformance battery); design 01/02 amendments recorded in their §11.
- **Erratum (2026-08-25)**: decision (5) above reads "gateway-injected **(signed header)**". There is no header signature and none is needed. Design 03 §3.4 and design 13 §3.3 both state that trust derives from the gateway's verified SVID on the mutually-authenticated provider connection, and design 13 records that design 03's wording was aligned to it (13 r1 f4) — this ADR and design 01 A1 were the two documents never corrected. Read decision (5) as "gateway-injected, provider-enforced; trust is the gateway SVID, not a header signature". The erratum is recorded rather than applied in place so the drift stays visible: an implementer working from this ADR alone would have built a signing key and a distribution path nothing else expects. Corrected alongside as design 01 **A8** and design 03 A5.
- **Amendments (2026-08-25)**: design 03 §11 A1–A4 sharpen decisions (1), (3) and (4) without reversing them — required-concerns (a route is never created without its mandatory policies, which is what makes (3)'s "no fail-open windows" true rather than merely ordered), the cold-start branch and the P1 test slice, a declared source for `gatewayReplicas`, and the arithmetic that makes (4)'s usd tier computable. No superseding ADR: nothing decided here is reversed.
