# ADR-0023: P2 knowledge layer (designs 11–15 + 19, consolidated)
- **Status**: accepted · 2026-08-20 (all six designs critique-PASS)
- **Connector (11)**: one CR, three facets, independent conditions. Event receiver is **split-mode by default** (internet-origin parsing never in the control-plane binary; local-profile embedding only); CloudEvents ids derived from source-event identity + `Nats-Msg-Id` dedup (the ADR-0021 lesson); poll cursors in KV, advanced after publish; **structured content mode** (released NATS binding blesses structured only); per-tenant EVENTS stream; CDC deferred explicitly. Continuous readers get a **per-connector, per-staging-version `write_batch`-only grant** (kgp admin authz is per-tool — design 01 A2); reader/catalog types are pack content.
- **Ontology (12)**: closed type system (no ref() attrs — entity-to-entity facts are relations; no arrays/nesting), canonical relation refs = full triple strings, invariant/recipe/generator sets closed (packs use, never define), **normative Pydantic derivation table** (descriptions are extraction prompts — mandatory), probe `via` required (q is a label), `health.pass_threshold` in the doc (CR may tighten only), `migrates` renames+removed acknowledgment grammar, `custom` invariants contained (read-only on staging; hardened profiles may deny).
- **Adapter (13)**: **extraction lives in the pipeline; the adapter is LLM-free** — `write_batch` is a structured upsert (graphiti lower-level persistence), Pydantic types configure typing/search only. **Version fork = deterministic data copy** (FalkorDB `GRAPH.COPY`, key-per-version; never re-extraction). Closed error set held (embedder mismatch = `KG_VERSION_GONE` + detail). Scope trust = gateway SVID on the mTLS connection.
- **Pipeline (14)**: Jobs-with-DBOS (0 standing pods) with a **park/resume lifecycle** (pause ⇒ workflow durably waits, Job exits; operator relaunches on review-resolution/budget-window). Gate A gates on the **Wilson lower bound**, advisory under `LabelsSparse` until n≥200, with a label growth engine (review resolutions + probe investigations); review queue never guesses, never silently expires, replay invalidated on ontology majors. Builds carry `build.budget` on the KG CR (`principal: build:<graph>@vN+1`).
- **Probes (15)**: probes are mechanical (`via` required); **stakes-split verification** — promotion = 100% engine-side execution (provider grades nothing at admission), continuous = self-report + 20% re-verify + standing conformance parity; `ProbeInfraError` ≠ `KnowledgeStale`; unprobed promotion only via explicit `--allow-unprobed`; `probes.budget` on the KG CR.
- **Patterns (19)**: `knowledge-pattern/v1` pack contract (zero executable content; self-certifying fixtures on the reference provider); `sop-decision-tree` fully specified (walk schema amended into ontology/v1 A2: entry/sequence/branch/state; conformance full-walk case in kgp A3); starter labels are an advisory smoke set; template descriptions named as a prompt-injection surface with layered containment.
- **Consequences**: the differentiator layer is fully designed; designs 01/02/03/12 carry the amendments; remaining backlog = P3 (16–18), P4 (20–24), P5 (25), ent (26–27).
