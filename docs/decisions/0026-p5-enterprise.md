# ADR-0026: P5 + enterprise — ModelHub, tenancy, compliance (designs 25–27)
- **Status**: accepted · 2026-08-20 (all three critique-PASS; design 26 at r3)
- **ModelHub (25)**: **one promotion mechanic, two metric families** — models reuse design 16's flow/contracts/fail-closed rules; model metrics are their own catalog (16 A1: golden_quality, latency/throughput, refusal_safety, cost-per-1k-tokens — never per-task). Shadow InferenceService gets a **candidate-only LLM route admitting just the eval run principal** (the 02-f2/16-r2 lesson); general Backend registration only on pass. **KServe RawDeployment is a stated constraint** (no Knative/Istio — the reason the binding respects rule 5 and ADR-0012). `kit://` resolves via a chart-shipped `ClusterStorageContainer`. The **operator writes `internal/<model>` pricing rows** so agent policy compilation never fails on an unpriced in-cluster model; receipt enum stays two-valued. Gateway-side weight shifting via agentgateway **virtual models** (minimum-version pin folded into 06-review R2-a).
- **Tenancy (26)**: the ADR-0013 thesis, tested and corrected — **two new mechanisms** (tenant-scoped quota intents extending the budget compiler; **per-tenant SPIRE federated to the host trust domain** via `ClusterFederatedTrustDomain`), everything else genuinely inherited. Hard mode **splits the control plane**: workload-managing operators run per-tenant inside the vCluster (no host credentials), the policy compiler stays host-side (host gateway write, tenant CR read only). Cost stated by tier (~4–5 pods core-only; +2–3 plus). Honest gaps recorded: soft-mode DBOS state is **not** RLS-isolated, and the shared runtime holds three credential classes. Tenant quotas inherit the approximation tier; exact tier = per-tenant rollup (04 A2). Delete requires export-first + explicit confirmation; IdP orgs deactivate.
- **Compliance (27)**: hash-chaining moves **downstream of the stream** — a single-writer chainer consumer chains over JetStream sequence numbers (parallel tap replicas cannot share a chain; 04 A3), which is also a stronger auditor statement. The `profile` facet **never mutates chart values**: declare → preflight emits a GitOps values delta → human applies → posture doc verifies (07 keeps sole ownership). Safeguard map de-overclaimed (ambient profile now mandated; "PHI minimization" not de-identification; audit proves access not post-redaction content; StorageClass mandated, CSI encryption is customer attestation) with the limits moved into the shipped §6. Compliance filters occupy the `compliance` priority band. **ADR-0015 held checkably**: OSS users can enable chaining and run `plume compliance verify` without a license.
- **Consequences**: the design phase is complete — 27/27 approved, every one through independent critique. Implementation may begin; the build order (architecture §18) and the contracts ledger govern.
