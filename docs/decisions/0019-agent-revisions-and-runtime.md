# ADR-0019: Agent revision model, card source-of-truth, workload materialization
- **Status**: accepted · 2026-08-20
- **Context**: Design 02. Eval-as-admission (ADR-0006) is incompatible with k8s rolling updates (old/new traffic mixes during rollout). Agent Cards can live in YAML or in the container. agent-sandbox reached v1beta1; agentgateway 2.2 split from kgateway (own CRDs).
- **Decision**: (1) The operator owns revisions: parallel content-addressed workloads per spec change, gateway route weight 0 while Held, gate controller shifts weights (canary steps), `revisionHistoryLimit: 2` for instant rollback. (2) Card source-of-truth is the container (`/.well-known/agent-card.json`), fetched/validated/digested by the operator; inline override only for external agents. (3) Workload default = Deployment (stateless A2A, replicas); `runtime.sandbox` ⇒ agent-sandbox Sandbox v1beta1 singleton; missing sandbox runtime ⇒ hardened-Deployment fallback + `SandboxDowngraded` condition. (4) Identity via one templated ClusterSPIFFEID + pod labels (spire-controller-manager, spiffe-csi) — no custom registrar. (5) Policy compilation targets agentgateway CRDs only. **Erratum (2026-08-27)**: this read "agentgateway 2.2"; no such release exists — the binding is **v1.4.1** (ADR-0028).
- **Consequences**: Blue-green cost (2× pods during rollout) accepted; card lies detected by digest; kgateway-era APIs never supported.
