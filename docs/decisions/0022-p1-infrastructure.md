# ADR-0022: P1 infrastructure decisions (designs 05–10, consolidated)
- **Status**: accepted · 2026-08-20 (all six designs critique-PASS)
- **Directory (05)**: OASF 1.1.0 records (verified live) on JetStream KV, dot-token keys (design 02 A2); adopt ADS *formats/exchange semantics* (OCI + Sigstore) without running ADS; **directory is discovery, never authz**; MCP-Registry federation is curated/explicit, imported records are never bindable by themselves; external publication only via explicit export; `dir.changed` CloudEvents are the audit (KV history=10 is convenience).
- **Identity (06)**: `idp/v1alpha1` profile slot with capability flags (Zitadel default, Keycloak profile w/ pinned exchange feature, byo = verify-exists mode). **On-behalf-of = RFC 8693 at the gateway** (verified OSS: `oauthTokenExchange` w/ actorToken/audiences/cache), per-agent `agent-actor` clients so `act` chains name real agents (design 02 A3); agents never hold user tokens; IdP outage fails human paths closed, machine mTLS paths continue; identity objects deactivate, never auto-delete.
- **Chart/CI (07)**: weight budget + stateful-allowlist (with reasons) CI-enforced; SPIRE datastore on platform Postgres; CNPG; core-tier gating contract = gates-required iff EvalSuite CRD present, loud `GatesSkipped`, downgrade refused mid-rollout (design 02 A4); `assayd-contracts` ConfigMap ledger operationalizes N/N−1; CRDs never rolled back (additive within N/N−1); chart itself cosign-signed OCI, digest-pinned, SBOM'd; k3d+kind per-merge, minikube+k3s weekly.
- **CLI (08)**: no template content in the binary (packs provide); wizard emits rerunnable flag sets (one path for TTY and CI); GitOps-first deploy with streamed rollout; doctor reads the contracts ledger and checks receipt liveness read-only (audit stream is never CLI-writable); read-only receipts cred minted per tenant at login; **no telemetry, ever default-off**.
- **Templates (09)**: P1 delivery = cosign-signed OCI artifact (degenerate pack; design-18 constraint recorded); card signing = Sigstore keyless builder identity riding `assayd build`, publisher-domain signatures at `expose: public`; unsigned BYO cards = loud `CardUnsigned` (design 02 A6); operator-owned injected env contract (A7); JetStream task store default-on; no runtime skill fetch in v1.
- **Observability (10)**: OpenObserve = sink never record; interior agent telemetry travels a compiled gateway route; **receipt discrimination is transport-derived** (gateway-SVID export listener mints receipts; forward-only listener never does — design 04 A1); signals/dashboards/alerts are fast-plane data behind a semconv name-map; metrics never carry per-task cardinality; alerts ship fixture-tested; no default credentials.
- **Consequences**: P1 is fully designed and internally consistent; design 02 carries amendments A1–A7 as the recorded cost of cross-design integration; implementation can start at design 02+03+07 concurrently.
