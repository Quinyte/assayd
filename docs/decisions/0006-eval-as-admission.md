# ADR-0006: Eval-gated progressive delivery (semantic admission)
- **Status**: accepted · 2026-08-20; **context corrected 2026-08-22** after an adversarial prior-art scan
- **Context**: 2026 practice runs eval gates as SaaS dashboards + CI scripts + gateway hooks. Recorded sessions make production traffic a free regression corpus.
- **Context correction (2026-08-22)**: the original wording — *"nobody expresses them as k8s rollout mechanics"* — was **wrong**, and the "first-mover window est. 12–18 months" that followed from it was wrong with it. [Flagger](https://docs.flagger.app/usage/webhooks) already holds a canary at weight 0, exposes a `-canary` service its own docs describe as "available only during the canary analysis… for conformance testing", runs `pre-rollout` hooks before any traffic reaches it, and records the outcome in `status.conditions` with a reason; [Argo Rollouts](https://argo-rollouts.readthedocs.io/en/stable/features/bluegreen/) `prePromotionAnalysis` + `previewService` is a near-tie. Gating promotion on *quality vs a baseline* is [TFX](https://www.tensorflow.org/tfx/guide/evaluator) "blessing". The rollout mechanics are mature k8s prior art and the gate content is mature ML prior art; plume **composes** them, which is ADR-0003 working as intended. This corrects a novelty claim, not the decision — see `docs/research/paper/01-eval-as-admission.md`.
- **Decision**: New Agent/Model versions are HELD with zero traffic until their EvalSuite (runner slot: DeepEval/Inspect; datasets = ontology golden set + replayed sessions) clears its gate; pass → gateway-weighted canary → 100%; fail → rollback with the report in CR status + PR. Models use the same gate.
- **Consequences**: P3 of the build order. **Not a differentiator** — describe it externally as eval-gated progressive delivery in the Flagger/Argo lineage whose gate content is an agent eval suite, never as something nobody does. The one property that genuinely distinguishes it: existing gates assume a **deterministic** verdict (Flagger's failure *threshold* is a noise filter for infrastructure flakes), whereas an eval is stochastic by construction, so N-of-M retry semantics silently become a **bias amplifier** — retry until pass. Treating gate non-determinism as a first-class controller concern is the defensible claim, and it is both unbuilt and untested.
