# ADR-0025: P4 — drift, workflows, governance, apps, ReBAC (designs 20–24)
- **Status**: accepted · 2026-08-20 (all five critique-PASS)
- **Drift (20)**: four families; remediation requires ALL of {deploy correlation, 1-action/24h rate limit, receipted, manual-override honored}; same-detector-verifies; baselines ratchet one way; **new installs run alert-only 14 days**; eval-passing-revision retention pinned while Degraded; core-tier rollback = "last-serving, not last-proven" (stated).
- **Workflows (21)**: interpreter over codegen (workflows stay data; runs pin interpreter+graph digests); +2 plus-tier pods ledger-entered, runtime scales 0→N; closed step kinds, no unbounded declarative control flow; run-id derivation per trigger kind (event/cron/http-Idempotency-Key/manual) — retries never double-run; **per-workflow `workflow-actor` clients** so gateway budgets/authz bite (the 16-lesson); in-runtime durable waits (DBOS sleep) for budget/approval parks; code-first = user pods + dynamic-queue enqueue.
- **Governance (22)**: lineage enforcement = stateless in-proxy CEL over a gateway-owned header (maxHops; **any-revisit-denied default**, opt-in occurrence-counted reentry); approvals = durable typed pendings + **single-use voucher consumed by gateway CEL — the operator never proxies tool data**; typed-pending retry added to the template contract; per-tenant APPROVALS bucket; kill = sticky guard state.
- **Apps (23)**: kro composes, assayd = watcher + compiler rows + client-gen; SSE chat = documented projection of A2A's own stream, **reconnect via A2A GetTask/SubscribeToTask — implementation-agnostic (BYO holds)**; generated client = fetch-based SSE (EventSource can't auth), sends Idempotency-Key; clients pin source digests, `app gen --check` is the CI skew gate; MemberSkew warns never blocks.
- **ReBAC (24)**: coarse CR-level objects (entity scope stays compiled); delegated traffic checks every attested `act` link, machine hops check the immediate SVID link, lineage never an authz subject; **user↔role facts via OpenFGA contextual tuples from verified JWT claims** (no directory sync; revocation ≤ cache TTL + token lifetime); FGA materializes CR-derived facts + Grant CRs only; no fail-open knob; shadow-first enablement; adapter co-located in the FGA pod; model bumps gated by decision replay from receipts.
- **Consequences**: the governance ring, self-healing, product layer, and layer-2 authz are fully designed; remaining backlog = 25 (P5), 26–27 (ent).
