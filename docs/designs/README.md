# Component design backlog

Design-first: every component gets a design doc (per `TEMPLATE.md`) approved **before** implementation. Order follows the dependency chain, not the build phases alone — contracts before consumers.

> **Scope reset, 2026-09-05 — ADR-0030.** "Critique PASS" on this table means a document survived adversarial reading. It does **not** mean the component is committed, buildable, or that any producer it names exists. The delivery commitment is now one end-to-end slice: designs **02, 03, 06, 07, 16** and the parts of **05** and **09** that slice needs. Designs **21, 23, 25, 26, 27** and the unimplemented parts of **11–14** and **18–19** are **hypotheses** — research retained, not prerequisites and not supported promises. Rows below are marked `HYPOTHESIS` accordingly. A row's PASS is evidence about the prose, and this project has now twice found a design whose central input was attributed to a producer that does not exist.
