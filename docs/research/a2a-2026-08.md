# A2A protocol — facts for designs 02/09 (2026-08)

- **A2A v1.0 shipped April 2026** — first stable spec: **signed Agent Cards** (cryptographic signature tied to the publisher's domain; verifiers check before trusting capabilities/auth schemes), multi-tenancy, version negotiation. Primary: https://a2a-protocol.org/latest/announcing-1.0/
- Card at `/.well-known/agent-card.json`; JSON-RPC 2.0 + SSE streaming; task lifecycle submitted→working→completed.
- Official SDKs: Python (`a2a-sdk`: AgentSkill/AgentCard/AgentExecutor), JS, Java, C#/.NET, Go, Rust. https://github.com/a2aproject
- plume signing model (design 09): Sigstore-keyless card signatures (builder identity) for platform-internal trust; publisher-domain signatures added at `expose: public` where A2A's cross-org model applies.
