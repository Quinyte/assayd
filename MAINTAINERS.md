# Maintainers

A foundation submission requires this table with real people in it — "TBD" and
"to be added after acceptance" are rejected — so it is a real table and not a
placeholder. Company is the affiliation under which the person maintains, which
matters because maintainer diversity is a graduation criterion and this project
currently has none: one maintainer, one company.

| Name | GitHub | Company |
|---|---|---|
| Quinyte Engineer | [@ejs-5](https://github.com/ejs-5) | Quinyte |

**This project is single-maintainer, and that is a stated risk rather than an
omission.** Flux is the cautionary case in the other direction: its commercial
steward shut down in February 2024 and the project survived only because
maintainership was already multi-vendor. Adding maintainers from outside Quinyte
is a precondition for any foundation submission being credible, not a nicety.

## Becoming a maintainer

There is no committee yet. Sustained, high-quality contribution — and, more than
volume, the judgement `CONTRIBUTING.md` describes: reproducing a finding before
fixing it, and knowing the difference between a test that passed and a claim
that is true — is what earns an invitation from the existing maintainers.
