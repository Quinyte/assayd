Diagrams on this target are generated `.webp` plates. There is no Mermaid and
no other diagram-as-code integration, by decision.

On a narrow screen the plate keeps its labels at a legible size and the frame
pans instead of shrinking. The frame is keyboard-focusable, so the arrow keys
pan it without a mouse.
